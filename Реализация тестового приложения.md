# Реализация тестового приложения

- Изначально был создан проект REST сервисов на основе **net/http** и **encoding/json**

- Предлагаемые оптимизации выходят за рамки первоначальных алгоритмов, поэтому в результате они будут выделены в отдельную <span style="color: red; font-weight: bold;">Blazing</span> категорию

- Получены 3 мёрджа с предложениями по оптимизации
  - **Sergey Neykovich**
    - Замена **net/http** на <span style="color: red; font-weight: bold;">fiber</span>
    - Замена **encoding/json** на <span style="color: red; font-weight: bold;">sonic</span>

  - **Ivan Berlin**
    - Реализация <span style="color: red; font-weight: bold;">Arena allocator</span> *Даёт максимальный прирост производительности*
    - Замена **net/http** на <span style="color: red; font-weight: bold;">fasthttp</span>
    - Замена **encoding/json** на <span style="color: red; font-weight: bold;">самостоятельную сериализацию</span>
    - <span style="color: red; font-weight: bold;">SIMD<span style="color: red; font-weight: bold;"> команды
    - Ограничение по количеству потоков

  - **quazar**
    - Реализация аллоцирование через <span style="color: red; font-weight: bold;">систему буферов</span> *Даёт максимальный прирост производительности*
    - Замена **net/http** на <span style="color: red; font-weight: bold;">fasthttp</span>
    - замена **encoding/json** на <span style="color: red; font-weight: bold;">segmentio/encoding</span>
    - <span style="color: red; font-weight: bold;">SIMD</span> команды
    - <span style="color: red; font-weight: bold;">Unsafe</span>
    - Оптимизация функций
    - <span style="color: red; font-weight: bold;">PGO</span> Сборка
    - **Ограничение по количеству потоков**

- Какие оптимизации и идеи были применены
  - <span style="color: red; font-weight: bold;">Arena allocator</span> Моя универсальная версия
  - <span style="color: red; font-weight: bold;">fasthttp</span>
  - <span style="color: red; font-weight: bold;">Самостоятельная сериализация</span> *Только из-за максимальной производительности, в реальных программах такая реализация явна не будет предпочтительной*
  - <span style="color: red; font-weight: bold;">Unsafe</span> для всех тестов, включая тест строк
  - **Ограничение по количеству потоков**
  - Оптимизация функций, кроме предложенных, я ещё сделал оптимизации всего того что можно
