# Реализация тестового приложения

- Изначально был создан проект REST сервисов на основе net/http и encoding/json

- Получены 3 мёрджа с предложениями по оптимизации
  - **Sergey Neykovich**
    - Замена **net/http** на **fiber**
    - Замена **encoding/json** на **sonic**

  - **Ivan Berlin**
    - Реализация **Arena allocator** *Даёт максимальный прирост производительности*
    - Замена net/http на fasthttp
    - Замена encoding/json на **самостоятельную сериализацию**
    - **SIMD** команды

  - **quazar**
    - Реализация аллоцирование через систему буферов *Даёт максимальный прирост производительности*
    - Замена **net/http** на **fasthttp**
    - замена **encoding/json** на **segmentio/encoding**
    - **SIMD** команды
    - **Unsafe**
    - Оптимизации функций
    - **PGO** Сборка

- Какие оптимизации и идеи были применены
  - **Arena allocator** была доработана, а так же сделана универсальной, через Generic базового типа, теперь один тип умеет аллоцировать разные типы данных. *В предложенном варианте было не универсально*
  - **fasthttp**
  - **Самостоятельная сериализация** *Только из-за максимальной производительности, в реальных программах такая реализация явна не будет предпочтительной*
  - **Unsafe** для всех тестов, включая тест строк
  - Оптимизации функций, кроме предложенных, я ещё сделал оптимизации всего того что можно

- Предлагаемые оптимизации выходят за рамки первоначальных алгоритмов, поэтому в результате они выделены в отдельную Blazing категорию
